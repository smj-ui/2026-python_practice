[4단계: 하루 동안 주가는 어떻게 변할까? ⚖️]

🎯 주가 변동 원리 이해하기 (함수)

  • 방어막 (±30%): 폭등/폭락을 막기 위해 1.3과 0.7을 곱해 상/하한가를 만듭니다.
  • 랜덤 체결강도: random.randint(-100, 100) 사이의 난수를 공평하게 뽑습니다.
  • 안전망 (min/max): 주가가 하한가로 떨어지면 max가, 상한가를 뚫으면 min이 방어합니다!
📝 실습
# 📝 4단계: 주가 변동 계산기(함수) 만들기
import random, time  

def 하루_주가_변동(종목코드): # 종목코드는 'A', 'B', 'C' 중 하나를 전달받는 매개변수입니다.
    # 미션 1: 상한가/하한가 방어막 치기 🛡️ (현재 가격의 ±30%)
    상한가 = int(종목_가격[종목코드] * [ 빈칸 1 ])
    하한가 = int(종목_가격[종목코드] * [ 빈칸 2 ])
    
    # 미션 2: 장 중 주가 변동시키기 ⏱️ (9시~15시 매 시간 거래 발생)
    for 시간 in range(9, 16):
        # -100부터 100까지 공평하게 뽑은 뒤 100으로 나눠 -1.0 ~ 1.0 사이를 만듭니다.
        체결강도 = [ 빈칸 3 ] / 100.0  # random 사용
        
        # (빈칸 4: 체결강도와 해당 종목의 민감도를 곱해서 변동률을 구하세요)
        변동률 = [ 빈칸 4 ]
        새_가격 = int(종목_가격[종목코드] + (종목_가격[종목코드] * [ 빈칸 5 ]))
        
        # 미션 3: 안전한 범위 내에 저장하기 🚧 (상/하한가 제한)
        종목_가격[종목코드] = [ 빈칸 6 ](상한가, [ 빈칸 7 ](하한가, 새_가격))
        
print("✅ 주가 변동 계산기(함수) 세팅 완료!")

for 일차 in range(1, 6):
    for 종목코드 in 전체_종목:
        하루_주가_변동(종목코드)

    수익률 = ((총_자산 - 초기_자본금) / 초기_자본금) * 100
    
    print(f"\n[{일차}일 차 마감] A: {종목_가격['A']:,}원 | B: {종목_가격['B']:,}원 | C: {종목_가격['C']:,}원")
    print(f"💼 내 계좌: {종목_이름[선택_종목]} {구매_수량}주 | 총 자산: {총_자산:,}원 | 수익률: {수익률:.1f}%")
    
    # 📈 흐름 3: 데이터 모으기 (오늘의 최종 가격을 바구니에 담기)
    가격_추이.append(종목_가격[선택_종목])
    time.sleep(0.5)

print("\n🏁 5일간의 주식 시뮬레이션이 모두 끝났습니다!")
