브레인스토밍이란?

브레인스토밍
창의적인 아이디어를 생산하기 위한 회의 기법. 집단적 창의적 발상 기법으로, 집단의 구성원들이 자발적으로 제시한 아이디어 목록을 통해 특정한 문제의 해답을 찾는 것

브레인스토밍의 과정

1관련자 모두가 참여하는 회의 소집
2경험 많은 사람을 회의 주재자로 선정
3테이블에 참석자를 배석시키고 종이 준비
4토론을 유도할 질문을 정함
5질문의 답을 종이에 적되, 한 장에 하나의 아이디어만 적어 참석자에게 돌려 봄
65번 단계를 5~15분간 반복
7간단한 설명
8모든 아이디어를 칠판에 적고, 우선순위를 정하기 위해 투표할 수도 있음

쓰레기 분리 배출 프로그램 만들기 (1)

엔트리의 이미지 분류 기능으로 쓰레기 분리 배출 프로그램을 만들어 봐요.

① 쓰레기 종류별 이미지 수집

1. 캐글(kaggle) 로그인 → 왼쪽 메뉴 ‘Datasets’
2. ‘garbage’ 검색 → ‘Garbage Classification (12 classes)’
3. glass, metal, paper, plastic 중 원하는 이미지를 각각 5장씩 내려받아 서로 다른 폴더에 저장

② 이미지 분류 모델 학습

1. 엔트리(playentry.org) 로그인
2. [만들기]-[작품 만들기]
3. [인공지능] 블록 → [인공지능 모델 학습하기] → [새로 만들기] → [분류: 이미지] → [학습하기]
4. 모델 제목(분리 배출), 클래스명(plastic, paper, metal, glass) 입력, 이미지 업로드 → [모델 학습하기]
💡 kaggle 로그인이 안 되면 크롬 확장 프로그램 ‘imageye’로 여러 이미지를 한 번에 내려받을 수 있어요. 엔트리 외에 ML4Kids, 티처블 머신도 활용 가능 p.194 날개
